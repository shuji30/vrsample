窓の外に公園のある部屋

× で閉じられます（I キーで開け閉め）

ヘッドセットのブラウザで開いて「ENTER VR」を押すと VR に入れます。

  • VR：トリガーでつかむ / 離すと投げる、左スティックで移動、右スティックでスナップターン
  • PC：W A S D / 矢印キーで歩く（Shift で速く）、ドラッグで視点回転、ホイールでズーム、クリックで小物を跳ねさせる
  • 掃き出し窓は開いています。そのまま歩いて庭へ出られます
  • キャッチボール：庭に出ると女の子もついてきます。ボールを投げると走って捕り、投げ返してくれます。VR は飛んでくる球へ手を出せば受けられます（PC は F で近くのボールを拾う / 投げる。飛んできた球は顔の前で自動で受けます）。ラリーが続くと少しずつ離れていきます
  • テニス：机の手前のラケットとテニスボールで打てます。庭の奥にテニスコートがあります。VR はラケットを握って腕を振る。PC は F でラケットとテニスボールを拾い、スペースでトスして打つ（ボールが無いときはスペースを押して振りかぶり、離して振る）。G でラケットを置く。コートの左後ろのボールかごから球を出せます（PC はかごのそばで F）。ラケットを持って庭へ出ると、女の子もコートでラケットを持って打ち返してくれます（持っている道具でキャッチボールとテニスが切り替わります）。PC はスペースを押したままにすると、届く球を自動で打ちます
  • カート：庭の右にカートコースがあります。カートに向けてトリガー（VR）かクリック / 近くで E（PC）で乗り、E / 左グリップ（0.5 秒）で降ります。VR は両手でハンドルを握る形にして傾ける、右トリガーでアクセル、左トリガーでブレーキ（止まってから踏み続けるとバック）、右グリップでハンドブレーキ、左スティックの押し込みで目線の合わせ直し。PC は W（アクセル）S（ブレーキ）A D、スペースでハンドブレーキ、C で視点。公園の左にはポケバイの小さなコースもあります（操作はカートと同じ。VR はハンドルバーを握って回す）。その手前のシーソーは、乗ると女の子が向かいに座り、下にいるとき W / 右トリガーでけると上がります。コーギーのこむぎが放し飼いで走りまわっています（クリック / VR は手を近づけてなでられます）。家の左のメリーゴーランドは、木馬に乗ると女の子が馬車に座って、いっしょに回ります。その左のブランコは、女の子が隣に乗り、W / 右トリガーでこぐと二人でそろって揺れます。さらに左の池では、桟橋のベンチに座って釣りができます（W / 右トリガーで投げる → 浮きがしずんだら押して合わせる → 押したまま巻く。女の子も隣で釣ります）。その奥の厩では馬に乗れます（はじめは女の子が引き馬で 1 周。そのあとは W / 右トリガーで速く、S / 左トリガーで遅く、A D / スティックで曲がる）。時間帯を夜にする（部屋のボタンか T キー）と、公園の奥で花火が上がります。家の右に飾ってある GT3 に乗ると、丘の東のふもとの広いサーキットへ移って、女の子と 3 周のレース（6 速。X / Z・RB / LB・VR の A / B でシフト、ハンコンのパドルも割り当てられます）。ハンコン・ペダルも使えます（H キーで設定とキャリブレーション、FFB）
  • ゲームパッド（PC）：左スティックで歩く、右スティックで見回す、A 拾う / 投げる、B ラケットを置く、X カートの乗り降り、Y 視点、RB 振る、RT / LT アクセル / ブレーキ、B ハンドブレーキ（運転中）
  • 女の子はしゃべります（ブラウザの音声合成。声の種類は端末しだい。?voice=off で消音。V キーで声を替えられます）
  • BGM はクリックすると鳴り始めます。M キーでオン / オフ（?bgm=off で最初から消音）
  • 右の壁のスイッチで昼 / 夕 / 夜が切り替わります
  • キャラクター（VRM）は部屋を歩きまわり、ときどきソファに座ります
