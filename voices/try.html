女の子の声の試聴（VOICEVOX）

VOICEVOX を起動した PC で開くと、声（キャラクターとスタイル）・速さ・高さ・抑揚を変えながら、ゲームの台詞をその場で聞けます。 気に入ったら、下の「作るコマンド」で全部の台詞を作ります（scripts/voicevox.mjs）。

1. VOICEVOX につなぐ

未接続

2. 声を選ぶ

3. 台詞を聞く

台詞を押すと、その声で読みます（一度作った音は覚えておくので、2 回目からはすぐ鳴ります）。

4. 作るコマンド

リポジトリの直下で、VOICEVOX を起動したまま実行します（初回だけ npm install）。全部の台詞をこの声で作り、voices/voicevox/ に入れます。

  • VOICEVOX（アプリ）を起動しておきます。エンジンは http://127.0.0.1:50021 で待ち受けます。

  • このページは、PC で npm start（リポジトリの直下）をして http://localhost:8080/voices/try.html で開くのが確実です

        許可するオリジンにそのページの URL（例 https://shuji30.github.io）を足します。それでもブラウザが止めることがあります。
