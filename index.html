窓の外に公園のある部屋

× で閉じられます（I キーで開け閉め）

ヘッドセットのブラウザで開いて「ENTER VR」を押すと VR に入れます。PC でもそのまま遊べます。

基本の操作

VRPC
歩く左スティックW A S D / 矢印（Shift で速く）
向きを変える右スティックドラッグ・ホイールでズーム
つかむ・投げるトリガーF（拾う / 投げる）
乗る・降りる乗り物にトリガー / 左グリップ 0.5 秒近くで E（どの乗り物も同じ）
乗り物の視点—C

家と庭

  • キャッチボール：掃き出し窓から庭へ出ると女の子もついてきます。投げると捕って投げ返してくれます（VR は飛んでくる球へ手を出して受ける）
  • テニス：机の手前のラケットを持って庭の奥のコートへ。VR は腕を振る、PC は スペースでトスして打つ・G でラケットを置く
  • カート（庭の右）：女の子と 3 周のレース。VR は両手でハンドル・右トリガー アクセル・左トリガー ブレーキ、PC は W / S / A D・スペースでハンドブレーキ

公園

  • シーソー・ブランコ：女の子が向かい / 隣に乗ります。W / 右トリガーでける・こぐ
  • メリーゴーランド（家の左）：木馬に乗ると女の子が馬車に座って一緒に回ります
  • 観覧車（その西）：女の子が向かいに座り、1 周 100 秒。てっぺん 26m から海が見えます
  • 池：桟橋のベンチで釣り（押して投げる → 浮きが沈んだら押して合わせる → 押したまま巻く）
  • 厩（池の奥）：乗馬。はじめは女の子の引き馬で 1 周、そのあとは W / S で速さ、A D で向き
  • ポケバイ（公園の左）：小さなコース。操作はカートと同じ
  • コーギーのこむぎが走りまわっています（クリック / VR は手を近づけてなでる）

海辺

  • 丘の北の縁（厩の東）の「海辺へ」の看板で、崖の下の砂浜へ（戻りは「丘の上へ」の看板）
  • ビーチバレー：女の子とネットをはさんで打ち合い、7 点先取。VR は手ではたく、PC は近くで F
  • 貝がら拾い（トリガー / クリック / F）、寄せては返す波

GT3 とサーキット

  • 家の右に飾ってある GT3 に乗ると、丘の東のふもとのサーキットへ移って女の子と 3 周のレース
  • シフト：X / Z・パッドの RB / LB・VR の右手 A / B（ハンコンのパドルも割り当てられます）
  • R（バック）：止まって 1 速からシフトダウン。R ではアクセルで後ろへ
  • VR では C（ハンコンに割り当てたボタン）で目線を運転席に合わせ直せます
  • AT / MT の切り替え：Q・パッドの十字キー上・VR の右スティック押し込み（AT のままシフトすると MT に）
  • 車内の画面と PC の右上にコースの地図（自分 青・女の子 ピンク）が出ます
  • フロントガラスの上にルームミラー。後ろの車が映ります（重いときは ?mirror=off）
  • ハンコン・ペダル：H キーで設定・キャリブレーション・ボタンの割り当て・FFB

そのほか

  • 時間帯：部屋のスイッチか T キーで昼 / 夕 / 夜。夜は海の上に花火が上がります
  • 女の子の声：V キーで声を替える（?voice=off で消音）。BGM：M キー（?bgm=off）
  • ゲームパッド（PC と VR）：左スティック 歩く、右スティック 見回す、A 拾う / 投げる、B ラケットを置く、X 乗り降り、Y 視点、RB 振る、RT / LT アクセル / ブレーキ（VR では、VR のコントローラーの電源を切ると、左スティックで歩く・右スティックで向きを変える・X 乗り降り・Y 目線の合わせ直し）
